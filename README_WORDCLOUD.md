# ☁️ 即時線上文字雲 (Realtime Word Cloud) 使用說明與簡介

這是一款專為多人協作與即時互動設計的**線上文字雲網站**。結合了高性能的 Canvas 自訂渲染技術與 Firebase Firestore 雲端即時資料庫，適用於課堂互動、活動破冰、團隊腦力激盪等多人在線共同發言的場景。

## 🎨 產品簡介與亮點

* ⚡ **多人即時同步**：任何使用者透過網頁輸入的詞彙，會在 **1 秒內即時同步**到所有打開此網頁的使用者螢幕上，文字雲會產生平滑旋轉與大小動態調整。
* 🧠 **中文/英文雙語分詞統計**：
  - **單一詞彙**：輸入單個詞彙直接送出（權重加權為 2）。
  - **整篇文章**：直接貼上長篇文章或短文，系統會自動進行智慧斷詞與詞頻統計（權重加權為 1）。
  - **停用詞過濾**：自動過濾「的、了、在、是、the、and、with」等常見無意義虛詞，確保文字雲內容精確聚焦。
* 📐 **阿基米德螺旋線擺放演算法**：使用精密的數學螺旋線搜尋碰撞算法，確保每個文字都有最佳落點且**絕不重疊**，並提供 25% 隨機文字旋轉。
* ✨ **極致視覺與互動體驗**：
  - 現代暗黑系毛玻璃卡片（Sleek Dark Mode & Glassmorphism）視覺風格。
  - 字詞採用隨機 HSL 發光霓虹漸層，滑鼠移過去會**放大、發光高亮**，並以 Tooltip 提示精確的出現次數。
* 📋 **詞彙頻率清單 (HTML List)**：右下角列出熱門字詞的次數排行榜，**點擊清單項目即可直接填入輸入框**，方便快速重複輸入。
* 🧹 **一鍵清空資料庫 (隱藏功能)**：點擊「不重複字詞數」區塊即可觸發重設資料庫，清空所有歷史資料以重新開始。

## 📖 使用操作指南

### 1. 輸入與更新文字雲
* **方法 A：輸入單一標籤（如：活動簽到、關鍵字回饋）**
  1. 在「**輸入單一詞彙**」框中輸入文字（上限 20 字，例如：`平安`、`喜樂`）。
  2. 點擊「**🚀 送出並更新文字雲**」，您的詞彙會以較高的權重立刻出現在文字雲中！
* **方法 B：貼上長文（如：文章分析、文章關鍵字提取）**
  1. 將整段文章貼入「**或貼上整段文章**」的大型文字框中。
  2. 點擊送出，系統會自動拆解文章，將高頻詞彙加入文字雲中。

### 2. 檢視詳細統計數據
* 在文字雲畫布上，將滑鼠游標移到任何詞彙上方，該詞彙會放大並發光，同時會彈出懸浮提示框，顯示**該詞彙被輸入的確切次數**。

### 3. 快速帶入發言
* 在右下角的「**詞彙頻率清單**」中，您可以看到大家最常輸入的詞彙排行榜。
* **直接點擊清單中的任何詞彙**，該字詞會立刻填入上方的輸入框中，省去手動打字的時間。

### 4. 重設資料庫 (系統管理)
* 當活動結束需要清空文字雲時，**點擊左下角的「不重複字詞數」統計區**。
* 在彈出的確認視窗中點選「確定」，資料庫就會瞬間清空，網頁字詞數也會即時歸零。
